## Removal of oil nozzles

1.  Remove crankshaft. (See [Cylinder block (3S-GTE) › Removal of engine](../engine-mechanical/cylinder-block-3s-gte.md#removal-of-engine))
2.  Remove oil nozzles (with relief valves).

    Using a 5 mm hexagon wrench, remove the bolt and oil nozzle. Remove the four oil nozzles.

    <figure markdown="span">
      ![](images/LU0577.webp#illustration){ width="80%" }
    </figure>

## Inspection of oil nozzles

**Inspect relief valves (oil nozzles)**

Push the valve with a wooden stick to check if it is stuck.

If stuck, replace the relief valve.

<figure markdown="span">
  ![](images/LU0614.webp#illustration){ width="80%" }
</figure>

## Installation of oil nozzles

1.  Install oil nozzles (with relief valves).

    Using a 5 mm hexagon wrench, install the oil nozzle with the bolt. Install the four oil nozzles.

    **Torque:** 93 kg-cm (81 in.-lb, 9.1 N·m)

    <figure markdown="span">
      ![](images/LU0593.webp#illustration){ width="80%" }
    </figure>

2.  Install crankshaft. (See [Cylinder block (3S-GTE) › Assembly of cylinder block](../engine-mechanical/cylinder-block-3s-gte.md#assembly-of-cylinder-block))
