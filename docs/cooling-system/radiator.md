# Radiator

## Cleaning of radiator

Using water or a steam cleaner, remove any mud and dirt from the radiator core.

!!! note "Notice"

    If using a high pressure type cleaner, be careful not to deform the fins of the radiator core. If the
    cleaner nozzle pressure is 30 – 35 kg/cm² (427 – 498 psi, 2,942 – 3,432), keep a distance at least 40 – 50 cm
    (15.75 – 19.69 in.) between the radiator core and cleaner nozzle.

## Inspection of radiator

1.  Inspect radiator (water filler) cap.

    Using a radiator cap tester, pump the tester and measure the relief valve opening pressure.

    **Standard opening pressure:** 0.75 – 1.05 kg/cm² (10.7 – 14.9 psi, 74 – 103 kPa)

    **Minimum opening pressure:** 0.6 kg/cm² (8.5 psi, 59 kPa)

    If the opening pressure is less than minimum, replace the radiator cap.

    <figure markdown="span">
      ![](images/CO0034.webp#illustration){ width="80%" }
    </figure>

2.  Inspect cooling system for leaks.

    1.  Fill the radiator with coolant and attach a radiator cap tester to the radiator (water filler) cap.
    2.  Warm up the engine.
    3.  Pump it to 1.2 kg/cm² (17.1 psi, 118 kPa), check that pressure does not drop.

        <figure markdown="span">
          ![](images/CO0964.webp#illustration){ width="80%" }
        </figure>

    If the pressure drops, check for leaks on the hoses, radiator or water pump. If no external leaks are found,
    check the heater core, cylinder block and head.

## Removal of radiator

<figure markdown="span">
  ![](images/CO0985.webp#illustration)
</figure>

1.  Disconnect cable from negative terminal of battery.

    !!! warning "Caution"

        Work must be started after approx. 20 seconds or longer from the time the ignition switch is turned to
        the "LOCK" position and the negative (`–`) terminal cable is disconnected from the battery.

2.  Remove front luggage under covers.
3.  Drain engine coolant. (See [Replacement of engine coolant › Drainage of engine coolant](replacement-of-engine-coolant.md#drainage-of-engine-coolant))
4.  Remove upper radiator support seal.

    Remove the seven clips and support seal.

    <figure markdown="span">
      ![](images/CO0987.webp#illustration){ width="80%" }
    </figure>

5.  [](){ #p-co-18 } Disconnect radiator hoses.

    <figure markdown="span">
      ![](images/CO1106.webp#illustration){ width="80%" }
    </figure>

6.  Remove front hood lock.

    Remove the two bolts and hood lock.

    <figure markdown="span">
      ![](images/CO0975.webp#illustration){ width="80%" }
    </figure>

7.  Disconnect radiator cooling fan connectors.

    <figure markdown="span">
      ![](images/CO0973.webp#illustration){ width="80%" }
    </figure>

8.  Disconnect water temperature sensor (w/ A/C) or switch (w/o A/C) connector.
9.  Remove radiator and cooling fans.

    1.  Remove the two bolts and upper support. Remove the two upper supports.
    2.  Remove the radiator and two cooling fan assembly.

        <figure markdown="span">
          ![](images/CO1155.webp#illustration){ width="80%" }
        </figure>

    3.  Remove the two lower supports.

10. Remove No.1 and No.2 cooling fans from radiator.

    Remove the three bolts and cooling fan. Remove the two cooling fans.

    <figure markdown="span">
      ![](images/CO1028.webp#illustration){ width="80%" }
    </figure>

## Installation of radiator

(See [Removal of radiator](#removal-of-radiator))

1.  Install No.1 and No.2 cooling fans to radiator.

    Install the cooling fan with the three bolts. Install the two cooling fans.

    <figure markdown="span">
      ![](images/CO1028.webp#illustration){ width="80%" }
    </figure>

2.  Install radiator and cooling fans.

    1.  Place the two lower supports in position on the body.

        <figure markdown="span">
          ![](images/CO0976.webp#illustration){ width="80%" }
        </figure>

    2.  Place the radiator and two cooling fan assembly in position on the body.

        <figure markdown="span">
          ![](images/CO1156.webp#illustration){ width="80%" }
        </figure>

    3.  Install the upper supports with the two bolts. Install the two upper supports.

        <figure markdown="span">
          ![](images/CO0973.webp#illustration){ width="80%" }
        </figure>

    !!! tip "Hint"

        After installation, check that the rubber cushion (A) of the supports are not depressed.

        <figure markdown="span">
          ![](images/CO1017.webp#illustration){ width="80%" }
        </figure>

3.  Connect water temperature sensor (w/ A/C) or switch (w/o A/C) connector.
4.  Connect radiator cooling fan connectors.

5.  [](){ #p-co-20 } Install front hood lock.

    Install the hood lock with the two bolts.

    <figure markdown="span">
      ![](images/CO0975.webp#illustration){ width="80%" }
    </figure>

6.  Connect radiator hoses.

    <figure markdown="span">
      ![](images/CO1106.webp#illustration){ width="80%" }
    </figure>

7.  Connect cable to negative terminal of battery.
8.  Fill with engine coolant. (See [Replacement of engine coolant › Refill of engine coolant](replacement-of-engine-coolant.md#refill-of-engine-coolant))
9.  Start engine and check for leaks.
10. Install upper radiator support seal.

    Install the support seal with the seven clips.

    <figure markdown="span">
      ![](images/CO0994.webp#illustration){ width="80%" }
    </figure>

11. Install front luggage under covers.
