# Troubleshooting

| Problem         | Possible cause                                                              | Remedy                          | Page          |
|------------------|------------------------------------------------------------------------------|----------------------------------|---------------|
| Engine overheats | Dirt, leaves or insects in radiator or condenser                             | Clean radiator or condenser      | [Radiator](radiator.md#radiator) |
|                  | Hoses, water pump, thermostat housing, radiator, heater, core plugs or head gasket leakage | Repair as necessary | |
|                  | Thermostat faulty                                                            | Check thermostat                 | [Thermostat](thermostat.md#thermostat) |
|                  | Incorrect ignition timing                                                    | Reset timing                     | [Installation of distributor](../ignition-system/distributor-3s-gte.md#p-ig-17) |
|                  | Electric cooling system faulty                                               | Inspect electric cooling system  | [On-vehicle inspection](electric-cooling-fans/radiator-cooling-fans-w-a-c.md#on-vehicle-inspection) |
|                  | Radiator hose plugged or rotted                                              | Replace hose                     |               |
|                  | Water pump faulty                                                            | Replace water pump               | [Water pump](water-pump.md#water-pump) |
|                  | Radiator plugged or cap faulty                                               | Check radiator and cap           | [Radiator](radiator.md#radiator) |
|                  | Cylinder head or block cracked or water passage clogged                     | Repair as necessary              |               |

!!! tip "Hint"

    Removal of the thermostat would have an adverse effect, causing a lowering of cooling efficiency. Do not
    remove the thermostat, even if the engine tends to overheat.
